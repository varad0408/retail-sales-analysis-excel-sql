# 📊 Retail Sales Analytics using SQL

## Project Overview

This project analyzes the **Sample Superstore** retail dataset using **MySQL** to uncover meaningful business insights from sales transactions.

The analysis focuses on customer behavior, product performance, regional trends, profitability, and sales performance. It demonstrates practical SQL skills through real-world business questions that are commonly encountered in data analytics.

---

## Business Objective

The goal of this project is to answer key business questions such as:

- Which products generate the highest revenue?
- Which customers contribute the most sales?
- Which categories and sub-categories perform best?
- Which regions and states are the most profitable?
- How do discounts affect profitability?
- Which products consistently underperform?

The insights generated can help support better business decisions related to sales strategy, inventory management, customer segmentation, and profitability.

---

## Dataset

**Dataset:** Sample Superstore

- Approximately **9,600+ retail transactions**
- Customer, product, order, sales, discount, and profit information
- Public dataset widely used for data analytics practice
